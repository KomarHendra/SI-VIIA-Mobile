Widget layout yang paling sulit saya rangkai adalah kombinasi antara Row dan Column di dalam sebuah ListView. Kesulitan utama terletak pada penanganan error overflow (kelebihan batas layar) pada baris teks yang panjang, karena widget Row mengharuskan saya membungkus Column dengan widget Expanded agar lebarnya menyesuaikan sisa ruang. Selain itu, menyusun margin dan padding yang proporsional agar tampilan antarmuka katalog buku tetap rapi di berbagai ukuran layar membutuhkan beberapa kali uji coba.
