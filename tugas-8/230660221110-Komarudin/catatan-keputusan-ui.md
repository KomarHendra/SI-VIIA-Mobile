# Catatan Keputusan UI

| Komponen Desain | Keputusan | Alasan (Berdasarkan Kebutuhan/Persona) |
| :--- | :--- | :--- |
| **Warna Benih (Seed Color)** | `Colors.teal` (Hijau Kebiruan) | Memberikan kesan akademis, tenang, dan mengurangi ketegangan mata bagi mahasiswa (Andi) yang sering melihat layar. |
| **Bentuk Status** | Kotak melengkung (*Rounded Container*) berlatar warna transparan | Membedakan secara kontras antara buku yang "Aktif" (hijau) dan "Terlambat" (merah) agar pengguna langsung waspada tanpa perlu membaca teks secara detail. |
| **Posisi Aksi Utama** | `FloatingActionButton.extended` di Kanan Bawah | Memudahkan akses ibu jari saat Andi (Persona 1) menggunakan ponsel dengan satu tangan saat berjalan di area kampus untuk mencari buku. |
| **Hierarki Teks** | Judul (Bold, 16sp) & Tenggat (Regular, 14sp, Abu-abu) | Pengguna (Andi) mengutamakan identifikasi judul buku terlebih dahulu. Informasi tambahan seperti tanggal tenggat dibuat lebih kecil agar antarmuka tidak terlalu padat. |
